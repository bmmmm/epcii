No server, no cookies, nothing kept: the code is generated by this page alone. A shared link carries the payment data in its #fragment, which browsers do not send in requests — but it stays an ordinary URL: in the browser history, which some browsers sync, and in clear text wherever you paste it. Downloaded files are named after the IBAN. Share both as carefully as the payment data itself.
